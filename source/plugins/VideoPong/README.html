What is it?

videopong.net is a video Source plugin for Resolume Arena/Avenue. It lets you search videopong.net for short clips right from within Resolume, pick one from a popup browser window, and it plays that clip as a live video source - no manual downloading or importing of files required.

Downloaded clips are cached locally, so picking the same clip again later doesn't re-download it.

this version only downloads the public 640×480 preview of each clip - the same low-res preview videopong.net shows on its website, not the full-scale original. support for full-resolution clips (with login) is possibly coming in a future version, but isn't available yet.

Install

  1. get VideoPong.dll
  2. copy VideoPong.dll into your Resolume Extra Effects folder, typically:
      %USERPROFILE%\Documents\Resolume\Extra Effects
  3. start (or restart) Resolume Arena/Avenue
  4. videopong.net will appear as a Source effect named videopong.net, ready to drop onto a layer or clip slot
videopong.net is currently Windows-only. the clip-search popup window and the "Open Cache Folder" button rely on Win32/GDI+ and don't work on macOS.

Operate

drop videopong.net onto a clip or layer like any other source. it exposes four controls:

controltypewhat it does
Browse Clips button opens a popup window to search videopong.net by keyword and pick a clip from the results. the clip downloads to a local cache and starts playing automatically once chosen.
Open Cache Folder button opens the folder where downloaded clips are cached, in Explorer.
Play on/off pauses or resumes playback of the current clip.
Loop on/off when on, the clip restarts automatically after it ends.

typical workflow:

  1. click "Browse Clips"
  2. type a search term and browse the thumbnail grid
  3. click a clip to select it - it downloads (if not already cached) and starts playing on the layer
  4. use "Play" and "Loop" to control playback as needed

until a clip has been picked, the source outputs a transparent frame.
